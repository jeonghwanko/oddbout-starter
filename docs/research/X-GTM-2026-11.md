# X에서 Grok 구독자 대상 GTM (2026-11-12)

> Grok 구독자가 oddbout-starter로 만든 **자기 캐릭터**를 X에 올리게 하는 계획.
> 1차 기능은 `fighter:social`(생성 없는 내보내기)이다. 사용법은 [SOCIAL-EXPORT](../SOCIAL-EXPORT.md)에 있다.

이 문서는 전략 기록이고 절차가 아니다. 수치마다 확인 수준을 붙였다.

| 표시 | 뜻 |
| --- | --- |
| **[O]** | 공식 문서에서 직접 확인 |
| **[3P]** | 서로 일치하는 제3자 자료 |
| **[U]** | 미확인(단일 출처, 서로 다른 출처, 또는 확인 불가) |

x.ai, help.x.com, grok.com은 조사 중 자동 조회를 막아서 소비자 요금은 공식 페이지로 확인하지 못했다. **[U]·[3P] 수치는 사용자용 문구에 쓰지 않는다.**

## 1. 무엇을 할 수 있나: Grok 구독자가 X에서 할 만한 것

| 포맷 | 무엇 | X에서의 쓰임 | 만드는 법 |
| --- | --- | --- | --- |
| 내 캐릭터 리액션 GIF 팩 | 여섯 표정(기본·피격·스머그·위기·사이드아이·KO)의 짧은 루프 | 답글. X에는 사용자 스티커나 커스텀 이모지가 없어서 리액션 GIF가 사실상 "이모지"다 [3P] | `fighter:social` reactions (생성 0) |
| 소개 4장 | 정면 그림 + 표정 셋 | "내 OC 소개" 게시물. 이미지 4장 한도 [O] | `post-set/` |
| 쇼케이스 루프 | 대기 → 콤보 → 강타 → 엔드카드 | 프로필 고정 게시물, 스레드의 첫 글 | `showcase.mp4` |
| 기술 하나씩 | 모션별 3–6초 루프 | "오늘의 기술" 연재, 투표 게시물 | `clips/` |
| 사이드아이 / KO 밈 | 표정 하나에 밈 문구 | 인용 게시물, 밈 유행에 올라타기 | `reactions/sideeye.gif`, `ko.gif` |
| Grok 표정 클립 (선택) | Grok Imagine이 실제로 움직이는 표정 | 더 풍부한 리액션. 구독 쿼터를 쓴다 | `grok-face` 준비 → 사용자가 요청할 때만 생성 |
| 내 선수 vs 네 선수 | 실제 대전 리플레이 링크 | 인용 챌린지 "내 OC랑 붙어 볼 사람" | 기존 `spar`·대전 공유 페이지 |

비슷한 유행이 이미 있다는 보도가 있다 [3P]: 셀카 → 8비트 스프라이트 시트 → 루프 GIF ([pixazo](https://www.pixazo.ai/blog/how-to-make-8-bit-sprite-sheet-gif), [Picsart](https://picsart.com/blog/pixel-trend-144p-to-1080p/)). 2026년 4월 XCreators의 Grok Imagine "Chibify everything" 챌린지 기록도 있다 [U, 출처 페이지 404]. ODDBOUT의 차별점은 **움직이는 사진이 아니라 실제로 싸우는 선수**라는 점이다.

## 2. 포지셔닝

**"내 캐릭터를, 내 Grok 구독으로, 움직이고 싸우게."**

- **자기 캐릭터.** 2025년 12월 Grok 이미지 편집 반발로 아티스트 보이콧이 있었다 [3P] ([IBTimes](https://www.ibtimes.co.uk/xs-generative-ai-image-edit-tool-ignites-backlash-users-fear-image-misuse-1765715)). Toyhouse 같은 OC 커뮤니티는 AI 그림을 금지한다 [3P]. "남의 그림 편집"이 아니라 "내 OC에 생명을"로 말한다.
- **내 구독.** 추가 구독이나 API 키가 필요 없다(킷의 Grok 경로는 `~/.grok/auth.json` 로그인을 쓴다). 내보내기 자체는 쿼터를 쓰지 않는다.
- **싸운다.** 결과물이 게임에 실제로 출전한다. 대전 리플레이가 다음 게시물이 된다.

## 3. 타깃

- **1순위:** SuperGrok 또는 X Premium+ 구독자 중 자기 OC, 프로필 캐릭터, VTuber 아바타가 있는 사람.
- **2순위:** 픽셀아트·격투게임 팬, 한국어와 영어권 서브컬처 계정.
- 구독 요금(SuperGrok 월 $30, Premium+ 월 $40 등)은 [3P]이고, 개편 예고가 있다 [3P] ([cryptobriefing 2026-09-30](https://cryptobriefing.com/spacexai-four-grok-pricing-tiers/)). 그래서 문구에 가격을 넣지 않는다.

## 4. 바이럴 루프

```
선수 완성 → fighter:social → 엔드카드 달린 쇼케이스·리액션 게시
      ↑                                     ↓
  자기 선수 생성 ← oddbout.com/?ref=x (첫 답글) ← 보는 사람
      ↓
  "내 선수 vs 네 선수" 인용 → 대전 리플레이 → 다시 게시
```

- **엔드카드와 구석 표시가 기본이다.** 사용자가 끌 수 있다. 내보낸 결과물에 워터마크를 넣어 성장한 사례가 있다: Kapwing [3P, 자체 보고] ([Kapwing](https://www.kapwing.com/blog/viral-how-we-used-watermarks-to-grow-a-startup/)).
- **링크는 본문이 아니라 첫 답글에.** API로 올릴 때 URL이 든 게시물은 $0.20, 일반 게시물은 $0.015다 [O] ([X API pricing](https://docs.x.com/x-api/getting-started/pricing)). 사람이 직접 올릴 때도 같은 관행을 권한다.
- **개인화된 결과물을 공유하게 만드는 루프의 선례.** Wordware "Twitter Roast"는 730만 명이 썼다고 자체 보고했다 [3P] ([Wordware](https://blog.wordware.ai/twitter-roast-ai-with-llm-orchestration)). 다만 바이럴 사용자가 돈을 내지 않는 경우가 많다는 경고도 있다 [3P] ([Failory](https://newsletter.failory.com/p/ai-powered-growth-loops)).

## 5. 단계

| 주차 | 할 일 | 산출물 |
| --- | --- | --- |
| W0 시드 | 메인테이너 선수(네라·모르네·루비아 등)를 `fighter:social`로 내보내 공식 계정에 10개 게시. 실제 업로드로 MP4·GIF가 받아지는지 확인해 기록 | 업로드 확인 기록, 첫 소재 |
| W1–2 런칭 | 런칭 스레드(만드는 과정 → 쇼케이스 → 리액션 팩) + `#ODDBOUTme` 챌린지: "내 OC를 선수로" | 해시태그 게시물 |
| W3–4 협업 | OC·VTuber 크리에이터와 협업. 본인 캐릭터만, 동의를 받고 진행. 크리에이터끼리 대전 | 협업 게시물, 대전 리플레이 |
| 이후 후보 | 아래 "보류한 기능" | — |

## 6. 지표

- `?ref=x`로 들어와 가입한 수, 그 계정이 만든 선수 수.
- `#ODDBOUTme` 게시물 수, 엔드카드가 보이는 게시물 수(수동 집계).
- 킷에는 텔레메트리를 넣지 않는다. 내보내기 횟수는 세지 않는다.

## 8. Grok 쪽 사실

- **Grok Imagine 영상** [3P]:
  - 2026년 2월: 이미지 → 영상 10초, 720p, 오디오 포함 ([TechSpot](https://www.techspot.com/news/111169-xai-launches-grok-imagine-10-10-second-720p.html)).
  - 2026년 3월: Extend from Frame으로 약 15초까지 늘릴 수 있다.
  - 더 긴 클립 소식은 [U]다.
- **쿼터** [U]: SuperGrok은 24시간에 약 20개라는 보고가 있다. 실패한 생성도 쿼터에 포함된다는 보고가 있다. 그래서 Grok 표정 클립은 **요청할 때만** 만들고, 결과를 모르면 다시 보내지 않고 `video-resume`으로 복구한다.
- **구독 공유 풀** [O]: Warp 문서(2026-11-10)에 따르면 유료 Grok 구독은 Grok chat, Grok Build, API가 **하나의 주간 사용량 풀**을 공유한다 ([Warp](https://docs.warp.dev/agent-platform/inference/grok-subscription/)). 이 OAuth 경로가 Imagine 생성까지 쓸 수 있는지는 [U]다.
- **Grok Build CLI** [3P]: 2026년 5월 공개 베타. AGENTS.md를 읽는다. 킷의 `.grok/skills/create-fighter`가 이 경로의 스킬이다.
- **X 앱 안의 Grok 이미지 생성·편집**은 2026년 1월부터 유료 전용이다 [3P] ([KTVZ](https://ktvz.com/news/2026/01/09/after-digital-undressing-criticism-elon-musks-grok-limits-some-image-generation-to-paid-subscribers/)). 사람이 직접 Grok 앱에서 만든 클립도 `--add-clip`으로 가져올 수 있다. 이 경우 Grok 워터마크가 남을 수 있다 [U].

## 9. 보류한 기능 (이유)

| 기능 | 보류 이유 |
| --- | --- |
| X API로 직접 게시 | 유료다(URL 포함 $0.20). 사용자의 X 토큰을 킷이 다뤄야 한다. 지금은 intent 링크와 사용자가 직접 첨부하는 방식으로 충분하다 |
| 소환형 `@ODDBOUT` 답글 봇 ("@ODDBOUT 이 그림 싸우게 해 줘") | 소환된 경우에만 답글을 허용한다 [3P]. AI 봇은 X 승인이 필요하다 [U]. 자동화 계정 라벨도 필요하다. 남의 그림을 받는 경로라 포지셔닝과 충돌한다 |
| 호스티드 선수용 사이트 "X용 다운로드" 버튼 | 호스티드 선수는 사용자 손에 로컬 패키지가 없다. 사이트(게임 리포 빌드·배포)를 거쳐야 해서 2차로 미룬다 |
| 일곱 번째 이후 표정 | 표정 목록은 게임과 공유하는 계약이고 서버가 검사한다. 확장 시트를 만든다면 패키지 밖의 별도 생성으로, 요청이 있을 때만 한다 |

## 10. 리스크

- **AI 그림 반발.** 자기 캐릭터라는 점, 화풍은 하우스 셀 채색 고정이라는 점을 앞세운다.
- **Grok 요금·쿼터 변동** [U]. 내보내기는 쿼터와 무관하게 동작한다.
- **X 정책 변경.** 자동화 없이 사람이 게시하는 흐름이라 영향이 작다.
- **업로드 미확인.** 무음 MP4와 GIF가 실제로 받아지는지는 W0에서 확인한다. 킷은 확인했다고 주장하지 않는다.
