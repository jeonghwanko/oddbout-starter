# 자동 등록·상태 표시 적대적 리뷰 — 2026-11-07

대상: 로컬 커밋 `4f779eb5`. 운영 배포·새 생성 없이 실패 입력, 등록 경합, 복구, 표시 상태를 점검했다.
아직 배포하지 않은 마이그레이션 파일을 보완했다. 적용된 DB 이력을 다시 쓰는 작업이 아니다.

| 심각도 | 확인한 결함 | 수정과 재현 검사 |
|---|---|---|
| P1 | 자동 등록이 한도 초과로 멈추면 profile이 저장되지 않는다. 기존 운영자 재시도는 이를 모션 미완료로 해석해 모션 제작으로 돌렸다 | 마지막 완료 이벤트에 등록 전환 실패를 기록. 재시도는 등록만 수행하고 소유권·한도·초안을 다시 검사. 한도가 그대로면 상태·preview 보존 |
| P2 | 두 등록 호출이 같은 대기 상태를 읽으면 뒤 호출이 `generation-state` 실패를 반환했다 | 실패 뒤 같은 소유자·같은 작업을 한 번 조회해 실제 등록 진행을 회수. 추가 POST 없음. 응답 유실과 재조회 실패도 검사 |
| P2 | 이미 등록이 시작된 뒤 요청한 다른 프로필을 무시하면서 성공으로 응답했다 | 동일한 프로필 재요청은 회수하고, 다른 변경은 `registration-profile-locked`로 명시적으로 거절 |
| P2 | 오래된 상태 응답이 최신 카드를 덮고, 등록 기록만으로 현재 출전 여부까지 단정했다 | 작업 갱신·조회 시각 비교, 출전 여부는 사이트에서 확인. 미지의 상태는 기다리라는 안내 대신 확인 필요 표시 |
| P2 | preview 누락은 DB 제약 오류가 되었고, 숫자·객체 이름도 최소 초안 검사를 통과했다 | preview 누락은 `invalid-result`, 잘못된 필수 텍스트 타입은 `invalid-profile`. 결과 보존 및 운영자 재시도의 재생성 방지 검사 |

재현용 4개 테스트는 수정 전 모두 실패했고 수정 후 통과했다. 추가로 소유자 조회 실패,
불확실한 등록 응답, 동일 요청 재호출, 다른 프로필 재호출, 상태 응답 순서, 후보 맥락 없는 이미지,
운영자 권한과 기존 운영자 재시도 경로를 점검했다.

실제 Edge 브라우저에서 합성 데이터로 제작 중·운영자 확인·등록 완료 카드의 렌더링과 브라우저 오류 없음을
확인했다. 실제 GPT 웹에 배포한 통합 검증이나 실시간 알림 검증은 아니다. 상태 카드는 조회 시점의 정보다.
전체 파일 계약 검사는 기존 패키지 검증기가 담당하며, 여기의 최소 초안 검사는 그 검사를 대체하지 않는다.

운영 반영은 [기존 변경 기록](HOSTED-REGISTRATION-STATUS-2026-11-07.md)의 DB·MCP 배포 절차가 필요하다.

## 두 번째 리뷰

대상: 첫 보완 커밋 `2b9b042a`. 추가 재현 4건이 수정 전 실패하는 것을 확인했다.

| 심각도 | 확인한 결함 | 수정과 재현 검사 |
|---|---|---|
| P2 | 한도 문제를 풀어 등록을 재개한 뒤 제출 호스트가 끊기면, 과거 등록 차단 이벤트가 다시 적용된다. 한도가 찬 상태에서는 기존 제출 복구까지 거절된다 | 차단 이후의 `register` 이벤트가 있으면 그 차단은 해소된 것으로 처리. 기존 제출 단계를 재개하며 등록 승인 이벤트를 중복 생성하지 않음. 최종 제출의 한도 검사는 유지 |
| P2 | 서버의 이미지 첨부 다운로드만 실패했어도, 유효한 서명 URL 미리보기까지 `previewPair` 조건 때문에 표시하지 못한다 | URL 대체 경로는 후보 상태·개수·키·소유 작업 경로·허용 출처로 검사. 인라인 첨부용 플래그와 분리하고 외부 URL 차단 유지 |
| P2 | ChatGPT의 현재 도구 출력보다 오래된 응답 메타데이터가 우선해 완료를 제작 중으로 표시한다 | 현재 출력을 기준으로 표시. 메타데이터의 이미지도 동일 출력일 때만 사용해 다른 버전의 후보 혼합 방지 |
| P2 | A 완료 → B 운영자 확인 → 지연된 A 응답 순서에서는 오래된 응답을 무시하며 B 화면을 그대로 남긴다 | 같은 작업의 최신 결과를 다시 표시. 결과 캐시는 최근 5개 작업으로 제한 |

추가 회귀 테스트는 등록 복구 1개와 UI 4개다. 메타데이터 이미지가 다른 후보와 섞이지 않으면서,
일치하는 출력의 인라인 이미지는 계속 표시되는 경우도 포함한다.

실제 Edge 브라우저에서 현재 출력 우선순위, 작업 전환 뒤 지연 응답, 첨부 없는 서명 URL 미리보기의
이미지 로드를 확인했다. 로컬 합성 응답과 요청 가로채기로 제공한 WebP를 사용했으며 브라우저 오류는 없었다.
이는 운영 저장소 다운로드·실제 GPT 호스트 연동·배포 완료의 증거가 아니다. 새 캐릭터 생성은 수행하지 않았다.
